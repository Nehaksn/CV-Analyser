# CV-Analyser

An AI-powered CV reviewer that analyzes resumes and provides feedback based on a target job role and job description.

## Features

- Upload a CV
- Enter candidate name
- Enter target job title
- Upload or paste a job description
- Analyze CV content
- Get feedback and suggestions
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
